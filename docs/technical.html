Sector Público — República de Panamá

Julio 2026

1. Descripción General

Aplicación web full-stack para la gestión de citas médicas en el sector público panameño. Permite el registro de pacientes, asignación de citas con doctores en sucursales, y administración del sistema con control de acceso basado en roles (RBAC).

5. Autenticación y Seguridad

  • JWT access token: 15 minutos de validez, firmado con JWT_SECRET
  • JWT refresh token: 7 días de validez, firmado con JWT_REFRESH_SECRET, con rotación (se invalida al usarse)
  • bcrypt: costo 12 para hash de contraseñas
  • MFA TOTP: opcional, via speakeasy + generación de QR code
  • Rate limiting: 100 requests por minuto (ThrottlerModule + Redis)
  • RBAC: roles admin, recepcionista, doctor, paciente — controlado por RolesGuard
  • Auditoría: AuditInterceptor registra todas las operaciones de escritura

9. Despliegue con Docker

9.1 Requisitos

  • Docker + Docker Compose
  • Node.js 20 LTS + pnpm 9.x (para desarrollo local)

9.2 Producción

docker compose up -d

El entrypoint ejecuta automáticamente migraciones de Prisma y datos iniciales (seed).

9.3 Desarrollo Local

docker compose up -d postgres redis
pnpm install
pnpm --filter api exec prisma migrate dev
pnpm --filter api exec ts-node prisma/seed.ts
pnpm run dev

11. Notas Técnicas

  • SWC Builder: NestJS usa @swc/core para compilar, evitando errores de validación de decoradores de TypeScript 4.9+. El type-checking se hace por separado en IDE/CI.
  • JWT Refresh Rotation: Cada vez que se usa un refresh token, se genera uno nuevo y el anterior se invalida. Previene reuso de tokens robados.
  • Prisma Migrations: En Docker se ejecutan automáticamente en el entrypoint del servicio api via prisma migrate deploy.
  • CORS: La API permite todos los orígenes en desarrollo (app.enableCors()).
  • Monorepo: Turborepo gestiona el orden de build (shared → ui → api, web, admin).
